# Free OS images

Free, open-source systems for the "Distributions" list, copied from https://i.copy.sh/ (made for the
v86 emulator by its author). They're kept here because i.copy.sh blocks downloads from other websites.

| File | System | License |
|---|---|---|
| buildroot-bzimage68.bin | Buildroot Linux | GPL ([source](https://buildroot.org)) |
| linux4.iso | Small Linux demo | GPL ([source](https://kernel.org)) |
| TinyCore-11.0.iso | Tiny Core Linux 11 | GPL ([source](http://tinycorelinux.net)) |
| dsl-4.11.rc2.iso | Damn Small Linux 4.11 | GPL ([source](https://www.damnsmalllinux.org)) |
| kolibri.img | KolibriOS | GPL ([source](https://kolibrios.org)) |
| freedos722.img | FreeDOS | GPL ([source](https://www.freedos.org)) |
| openbsd-floppy.img | OpenBSD installer | BSD ([source](https://www.openbsd.org)) |

Windows isn't here: it isn't free. Use your own copy with "Your own OS file".
