Info
What runs: 32-bit PC systems: Windows 95, 98, ME, 2000, XP (32-bit), DOS, Windows 3.1, 32-bit Linux, BSD.
What can't: 64-bit systems (Windows 7/10/11 64-bit, 64-bit Linux). The emulator is a 32-bit PC, and no free browser emulator runs 64-bit at a usable speed.
Windows: it's not free, so it isn't included. Use your own copy as a file above. A hard disk image with Windows already installed is easiest. Windows 95 CDs usually need a boot floppy too.

How images load:
The full image is downloaded then handed to the emulator as an in-memory buffer — no CORS issues inside the VM.
Fallback proxy: allorigins.win

Custom URLs need
Access-Control-Allow-Origin: *
or prefix with:
https://api.allorigins.win/raw?url=
